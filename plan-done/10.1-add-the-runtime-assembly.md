# 10.1 Add the runtime assembly

## What was done

- Moved `PushButton.cs`, `PushButtonManager.cs` and their program assets (`PushButton.asset`, `PushButtonManager.asset`), each with its `.meta`, from `Assets/PushButton/` to `Packages/io.siggi.pushbutton/Runtime/` with `git mv`. GUIDs are unchanged, so the scene's references didn't change (the scene file has no diff).
- Added `Runtime/SiggiPushButton.asmdef` (references `VRC.SDKBase`, `VRC.SDK3`, `VRC.Udon`, `UdonSharp.Runtime`) and its UdonSharp assembly definition asset `Runtime/SiggiPushButton.asset`, made like `SiggiUSTools.asmdef` / `SiggiUSTools.asset`. No `rootNamespace`, since the classes are in the global namespace.
- Recompiling rewrote the program assets' serialized type names from `Assembly-CSharp` to `SiggiPushButton` (`PushButtonManager, SiggiPushButton` and `PushButton[], SiggiPushButton`). That's expected.
- The editor scripts and tests in `Assets/PushButton/Editor/` (Assembly-CSharp-Editor) still compile: they reach the runtime classes through the auto-referenced asmdef, and none of them use `internal` members of the runtime classes.
- Updated the Play Mode tests' `ButtonProgramPath` to `Packages/io.siggi.pushbutton/Runtime/PushButton.asset`. Without it, the `no manager` test failed to load the program asset (1581 passed, 1 failed). 10.4 still moves the tests and updates the other paths.
- Also committed the package's registration, which was already in the working tree: `package.json`, the `!io.siggi.pushbutton/` line in `Packages/.gitignore` and the embedded package in `Packages/packages-lock.json`.
