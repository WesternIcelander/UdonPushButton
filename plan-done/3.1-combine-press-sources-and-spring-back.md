# 3.1 Combine press sources and spring back

added private `localPress`, `remotePress`, `clickPress` and `pressAmount`. `UpdatePressAmount()` clamps the max of the three to `[0, travelDistance]`, jumps straight to it when deeper, and otherwise `MoveTowards` it at `returnSpeed * Time.deltaTime`; `Update` then calls `ApplyPress(pressAmount)`. `debugPressSlider` is gone. In its place `debugLocalPress` (`[Range(0, 0.03)]`, marked `TEMP (plan step 3.1)`, remove in 5.3) is copied into `localPress` each frame. The harness's `AddPressTest` now sets `returnSpeed` to 0.01 m/s, presses with `debugLocalPress = 0.03`, and checks that `pressAmount` is exactly `travelDistance` 0.5 s later (easing in would only have reached 0.005), with the button 1 mm in front of the plate at (0, 1, 0.011) when unrotated. Then it releases and checks that 0.5 s later the press is part-way back at the expected rate (0.0140 measured, 0.0140 expected) and the position matches. Finally it restores `returnSpeed` and checks the button is back at rest. It runs unrotated and with the parent at (35, 120, -70). UdonSharp compiled 10 scripts with no errors. Result: `[PushButtonTest] done: 43 passed, 0 failed`, 0 errors (the trigger again only left Play Mode at "time up"). The scene file never stored `debugPressSlider`, so it needs no change.
