# 2.2 Compute the contact box

`ComputeContactBox()` runs in `Start` after the rest pose. It stores `pressAxis` (normalized `localPressAxis`; a zero axis logs a warning and falls back to (0, 0, -1)), two perpendicular unit axes `lateralAxisU` / `lateralAxisV`, `frontFaceOffset`, and `footprintCenterU/V` plus `footprintHalfU/V`, all in meters in the rest frame (rotation only, scale applied via `lossyScale`). Arbitrary axes use the box's support distance along each axis. **Sign convention:** `frontFaceOffset` is positive, the distance from the rest position to the front face measured *against* `pressAxis` (the front face sits at `depth = -frontFaceOffset` when `depth = Dot(p, pressAxis)`). So in 5.3 the press formula `depth - faceOffset + radius` becomes `depth + frontFaceOffset + radius`. Added `AddContactBoxTest` to the Play Mode harness. Result: `contact box: face 0.0100, footprint 0.0250 x 0.0250, axis (0, 0, -1)`, `[PushButtonTest] done: 12 passed, 0 failed`, 0 errors. (The trigger's `play` saw the done line at once but only left Play Mode about 3 minutes later with "time up", which looks like a trigger quirk, not a test problem.)
