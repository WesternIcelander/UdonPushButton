# 2.3 Apply a press amount

`ApplyPress` uses the normalized `pressAxis` from 2.2 (not the raw `localPressAxis`), so a non-unit Inspector axis still moves exactly `amount` meters. The temporary slider is `debugPressSlider` (`[Range(0, 0.03)]`, under the Debug header), and `Update` calls `ApplyPress(debugPressSlider)` after rebuilding the rest pose. Both are marked `TEMP (plan step 2.3)`, to be removed in 3.1. Added `AddPressTest` to the Play Mode harness. It sets the slider to 0.02 with `SetProgramVariable`, checks the position against the formula and that the offset in the parent's space is (0, 0, -0.02), then sets it back to 0 and checks the button returns to rest. It runs once unrotated (button at the plate face, (0, 1, 0.01)) and once after the rest-pose test has rotated the parent to (35, 120, -70). Result: `[PushButtonTest] done: 21 passed, 0 failed`, 0 errors. The test drives the slider variable, not the Inspector by hand.
