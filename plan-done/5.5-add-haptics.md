# 5.5 Add haptics

`UpdateFingertipPresses` now also records `localPressHand` (`VRC_Pickup.PickupHand`). This is the hand of the local player's deepest pressing fingertip: even slots are Left and odd slots are Right. It's `None` when the debug fingertip leads or nothing presses. When `UpdateTrigger` fires and `localPress` (not the click) reached the bottom, `PlayPressHaptics()` calls `PlayHapticEventInHand(localPressHand, 0.08 s, hapticStrength, 320 Hz)` on the local player. The duration and frequency are new constants, `HapticDuration` and `HapticFrequency`. It's skipped when `hapticStrength <= 0`, the hand is `None` (a click, or the debug fingertip), or the local player isn't valid or isn't in VR. The pulse plays even if the target or event name is unset, because the button still bottomed out. **Harness:** `MoveButtonOntoIndex(player, press, left)` generalizes `MoveButtonOntoLeftIndex` to either hand. New `AddHapticsTest` hooks `VRCPlayerApi._PlayHapticEventInHand` to record calls. ClientSim's own handler only logs, and only when its logs are on. The test unhooks on exit. With the local player simulated as VR, a left index press fires and pulses Left at 0.3. A right index press fires and pulses Right. With `hapticStrength` 0 it fires without a pulse. The debug fingertip fires without a pulse. UdonSharp compiled 10 scripts with no errors. Result: `[PushButtonTest] done: 290 passed, 0 failed`, 0 errors (the trigger again only left Play Mode at "time up"). Nobody has felt the pulse yet; that's for the Phase 7/8 VR test.
