# 10.5 Check the package from outside

## What was done

- Package contents: `git ls-files Packages/io.siggi.pushbutton` holds only `package.json`, `Runtime/` (`PushButton`, `PushButtonManager`, their program assets, the `SiggiPushButton` asmdef and its UdonSharp asset), `Editor/` (inspector, build check, wiring, `AssemblyInfo.cs`, the `SiggiPushButton.Editor` asmdef) and the `Example~/` sample. No tests or test-only tools. The `Example` link is untracked (in `.git/info/exclude`), so it doesn't ship. Nothing in `Runtime/` or `Editor/` references ClientSim, the tests or the sample. The only test-facing line left is `InternalsVisibleTo("PushButtonTests.Editor")`, which is harmless outside this project.
- `package.json`: version `1.0.0-snapshot` (bump it at release), `unity` `2022.3` / `22f1`, `vpmDependencies` `com.vrchat.worlds ^3.10.4` (the SDK here is 3.10.5), sample path `Example~`. Same layout as `io.siggi.ustools`. No changes were needed.
- Clean project: copied VCC's `World` template (`%LOCALAPPDATA%\VRChatCreatorCompanion\VRCTemplates\World`, empty `Assets/`) to `D:\Siggi\Desktop\VRChat\VRCProjects\PushButtonCleanCheck`, added `com.vrchat.base`, `com.vrchat.worlds` 3.10.5 and the VPM resolver, and installed the package the way it ships, from `git archive HEAD Packages/io.siggi.pushbutton`, listed in `vpm-manifest.json`. Added the editor trigger and a temporary editor script that imports the sample through `Sample.FindByPackage(...).Import()`, opens its scene, and clicks the button through ClientSim's `ClientSimUdonHelper.Interact` 5 s into Play Mode.
- The first try was in the scratchpad under `%TEMP%`. Its path was too long: UdonSharp threw `DirectoryNotFoundException` on files deep in `com.vrchat.worlds` (Windows' 260-character path limit). This came from the location, not the package. A project under a short path works.
