# 2.1 Cache the rest pose

`Start` caches the local rest pose and `Update` calls `UpdateRestWorldPose()` (parent `TransformPoint` / `rotation *`, or the local values if there is no parent). A temporary `[PushButton] rest local … rest world …` log in `Start` (marked `TEMP (plan step 2.1)`, to remove by 7.2) printed `(0, 0, 0.03)` local and `(0, 1, 0.03)` world. To test in Play Mode, the `PushButton` component was added to the child `Button/Button` (all Inspector values at their defaults, no target yet) and the scene was saved. Added `Assets/PushButton/Editor/PushButtonPlayModeTests.cs`, an editor-side Play Mode harness that later steps can extend: `menu Tools/PushButton/Run Tests On Next Play` arms it, then `play 120 [PushButtonTest] done` runs it. It reads the Udon variables with `GetProgramVariable`, moves the parent by (1, 0.5, -2) and rotates it to (35, 120, -70), and checks the rebuilt rest pose against the parent's transform. Result: `[PushButtonTest] done: 7 passed, 0 failed`, with 0 errors in Play Mode. It also has `menu Tools/PushButton/Add PushButton To Scene Button`, which does nothing if the component is already there.
