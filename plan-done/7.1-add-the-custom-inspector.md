# 7.1 Add the custom inspector

`PushButtonEditor` (`[CustomEditor(typeof(PushButton))]`) draws UdonSharp's default header, then every visible serialized property (headers and tooltips included) with `eventName` swapped for a popup. UdonSharp hosts it inside its own `UdonSharpBehaviourOverrideEditor` (as `_userEditor`), which is how custom U# inspectors work. `GetEventNames(UdonBehaviour)` gets the class with `UdonSharpEditorUtility.GetUdonSharpBehaviourType` and lists its public, parameterless, non-generic instance methods (inherited ones down to `UdonSharpBehaviour`), leaving out property accessors and overrides of built-in events (`Interact`, `OnPlayerJoined`, …), sorted. It returns null for no target or a non-UdonSharp (Graph) program, and the field is then a plain text field; a target with no callable methods shows the text field plus a warning. A current event name that the target doesn't have stays selectable as "name (not found)" (or "(none)" when empty), so it's never silently replaced. Multi-object editing with differing values falls back to the text field. **Harness:** new `AddInspectorTest` (last). `Editor.CreateEditor` on the scene button's `PushButton` hosts a `PushButtonEditor`. An `UdonBehaviour` with `ButtonActionExample.asset` as its program source lists exactly `OnButtonPressed`. No target and an `UdonBehaviour` without a program both give null (text fallback). The scene button's own list includes `NetPlayClickAnimation` and leaves out `Interact`, `OnPlayerJoined` and `GetType`. The popup's drawing itself wasn't checked by eye (nobody at the PC). UdonSharp compiled 10 scripts with no errors. Result: `[PushButtonTest] done: 374 passed, 0 failed`, 0 errors.
