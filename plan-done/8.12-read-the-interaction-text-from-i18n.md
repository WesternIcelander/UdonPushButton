# 8.12 Read the interaction text from I18n

## What was done

- **Dependency.** Added `"io.siggi.ustools": "^1.0.0"` to the package's `vpmDependencies`, and `SiggiUSTools` to the references of the `SiggiPushButton` and `PushButtonTests.Editor` asmdefs.
- **Button.** Added `public SiggiUSTools.I18n i18n` to `Setup`, under `manager`. The custom inspector draws every visible field, so it shows up with no editor change. `TryListenToI18n` runs from `OnEnable` after the manager check and calls `GetCurrentLanguage`. A null result retries next frame through `_RetryListenToI18n`, and a non-null one adds the listener once and calls `_UpdateInteractive`. `OnLanguageChange` calls `_UpdateInteractive`, which reads `i18n._(interactText)` only while listening and with a non-empty text.
- **One addition to the plan.** An I18n whose UdonBehaviour is disabled counts as switched off, like one on an inactive GameObject: one warning, no retry. Otherwise a never-started, disabled I18n would be retried every frame for as long as the button is enabled. The warning is logged once per button, however often the button is enabled.
- **Scenes.** `VRCDefaultWorldScene` and the sample scene each have an `I18n` at the root with Main I18n set and `en` and `is` packs, and their buttons are wired to it (a temporary editor script did this and was deleted). Test packs are in `Assets/PushButtonTests/languages/`, and also hold a `test_key` so the tests can tell a translation from its key. The sample's are in `Example~/languages/`.
- **Tests.** New `PushButtonPlayModeTests.I18n.cs` (`AddI18nTest`), plus an inspector check.
