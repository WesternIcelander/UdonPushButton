# 2.4 Add gizmos

`OnDrawGizmosSelected` and a public `GetGizmoGeometry(...)` sit in a `#if !COMPILER_UDONSHARP && UNITY_EDITOR` block, so UdonSharp skips them and they run as plain C# on the editor-side component. It draws the rest box (cyan wire), the full-travel box (orange wire) and a yellow arrow along the press axis ending at the front face. The geometry comes from `ComputeContactBox`, which now takes a `warn` flag (so gizmo repaints don't spam warnings) and also stores `contactCenter` / `contactHalfExtents`. In Edit Mode the rest pose is the current transform; in Play Mode it's read from the Udon program's `restLocalPosition` / `restLocalRotation` plus the parent, so the boxes stay put while the button moves. Added `AddGizmoTest` to the harness (run unrotated and after rotating the parent to (35, 120, -70)): rest pose matches Udon's, rest box is 0.05 × 0.05 × 0.02 centred, and the full-depth front face is 1.00 mm in front of `ButtonPlate`'s face in both cases. Result: `[PushButtonTest] done: 35 passed, 0 failed`, 0 errors. The gizmo drawing itself wasn't looked at (nobody at the PC); only its geometry was checked.
