# 3.2 Add local-only triggering with arming

added a private `armed` flag (starts true) and `FireTolerance = 0.0005f`. Each frame `Update` calls `UpdateTrigger(clamp(localPress, 0, travelDistance))` before `UpdatePressAmount`. It fires when armed and the local press is `>= travelDistance - FireTolerance`, then disarms. It re-arms when the press is `<= travelDistance * releaseFraction` and also below the fire depth, so `releaseFraction = 1` can't re-fire every frame. `FireAction()` logs a `[PushButton] <name>: pressed, but no target behaviour / event name is set` warning instead of throwing. Only `localPress` reaches the trigger. In 4.2 the local click has to feed `UpdateTrigger` too (e.g. pass `max(localPress, local clickPress)`), and networked clicks must not. Haptics are left for 5.5. Added `AddTriggerTest` to the harness. In Play Mode it creates a `PushButtonTestActionTarget` object with an `UdonBehaviour` running the `ButtonActionExample` program (`AssignProgramAndVariables` + `InitializeUdonContent`), points the button at it with `OnButtonPressed`, and counts `[ButtonActionExample] pressed` log lines. It checks two full sweeps (fires once at the bottom, no refire while hovering 0.5 s, re-armed after release), a partial sweep (bottom → 75% → bottom fires only once), and that `remotePress = 0.03` alone moves the button to `travelDistance` without firing or disarming. Afterwards it restores the target and event name and destroys the object. Result: 3 action logs, `[PushButtonTest] done: 65 passed, 0 failed`, with no errors or exceptions in the log. The older press tests now log the expected "no target behaviour is set" warning, because the scene button has no target until 7.2.
