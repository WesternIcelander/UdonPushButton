# 10.3 Move the example into the sample

## What was done

- Moved `ButtonActionExample.cs` and its program asset `ButtonActionExample.asset`, each with its `.meta`, from `Assets/PushButton/Examples/` to `Packages/io.siggi.pushbutton/Example~/` with `git mv`, and removed the empty `Examples` folder. GUIDs are unchanged.
- Unity doesn't compile a script in a package unless an asmdef covers it ("will not be compiled because it exists outside the Assets folder and does not belong to any assembly definition file"). So the sample got its own `SiggiPushButton.Example.asmdef` (references `VRC.SDKBase`, `VRC.SDK3`, `VRC.Udon`, `UdonSharp.Runtime`) and its UdonSharp assembly definition asset `SiggiPushButton.Example.asset`, made like the runtime ones. The script then compiles into `SiggiPushButton.Example` both through the `Example` link here and when the sample is imported into `Assets/Samples/` in another project. Its type is defined once in either case. (Importing the sample into this project as well would add a second copy, so don't do that here.) Assembly-CSharp-Editor (the tests) reaches it through the auto-referenced asmdef.
- Added the example scene `Example~/PushButtonExample.unity`. It holds a directional light, a floor, the SDK's `VRCWorld` prefab (spawn at z = -1.5, with no world ID), a `PushButtonManager` at the root, and a `PushButtonAssembly` laid out like the test scene: a plate, plus a `Button` cube with `PushButton` that is pressed along local -Z, with the parent turned 180° on Y to face the spawn. There's also a `ButtonAction` object with `ButtonActionExample`, which toggles a `ToggleTarget` sphere. The button calls its `OnButtonPressed`, `OnButtonReleased`, `OnAnyonePressed` and `OnAnyoneReleased`, and `PushButtonWiring.Fix` wired it to the manager. A temporary editor script built the scene and was deleted afterwards.
- Updated the Play Mode tests' `ExampleProgramPath` to `Packages/io.siggi.pushbutton/Example/ButtonActionExample.asset` (through the link). 10.4 moves the tests.

## How it was checked

- `refresh`, then `Re-compile All Program Sources`: no compile errors, and `Library/ScriptAssemblies/SiggiPushButton.Example.dll` was built.
- Opened the example scene and entered Play Mode, with a temporary script that clicked the button through ClientSim (`ClientSimUdonHelper.Interact`). `CanInteract` was true, the click logged `[ButtonActionExample] pressed by [1] Local Player` and `[ButtonActionExample] anyone pressed`, and the sphere was turned off. `Play Mode ended, 0 errors logged`.
- Full Play Mode run in the main scene: `[PushButtonTest] done: 1590 passed, 0 failed`, `Play Mode ended, 0 errors logged`. The count is the same as before.
- Build-check tests: `[PushButtonBuildCheckTest] done: 114 passed, 0 failed`.
- Importing the sample into another project is left for 10.5, which installs the package into a clean project.
